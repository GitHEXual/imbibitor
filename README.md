# RAG система для поиска и генерации постов

RAG (Retrieval-Augmented Generation) система для поиска похожих сообщений по смыслу и генерации постов на основе найденных сообщений.

## Особенности

- **Семантический поиск** - поиск по смыслу через embeddings (nomic-embed-text)
- **Гибридный поиск** - комбинация семантического и keyword поиска (BM25) с использованием Reciprocal Rank Fusion
- **Генерация постов** - создание постов на основе найденных сообщений через LLM (devstral-2:123b-cloud)

## Требования

- Python 3.8+
- Ollama установлен и запущен
- Модели Ollama:
  - `nomic-embed-text` для embeddings
  - `devstral-2:123b-cloud` для генерации текста

## Установка

1. Активируйте виртуальное окружение:
```bash
source venv/bin/activate
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Убедитесь, что Ollama запущен:
```bash
ollama serve
```

4. Убедитесь, что модели установлены:
```bash
ollama pull nomic-embed-text
ollama pull devstral-2:123b-cloud
```

## Использование

### Индексация сообщений

Индексирует сообщения из `data/result.json` в векторную базу данных:

```bash
python cli.py index
```

Опции:
- `--data-path` - путь к файлу result.json (по умолчанию: `data/result.json`)
- `--db-path` - путь к базе данных ChromaDB (по умолчанию: `./chroma_db`)
- `--ollama-url` - URL Ollama API (по умолчанию: `http://localhost:11434`)
- `--embedding-model` - модель для embeddings (по умолчанию: `nomic-embed-text`)
- `--batch-size` - размер батча для обработки (по умолчанию: 100)

### Поиск похожих сообщений

Ищет похожие сообщения по запросу. Поддерживает два режима:

**1. Гибридный поиск (по умолчанию)** - комбинирует семантический и keyword поиск:
```bash
python cli.py search "ваш запрос" --top-k 5 --hybrid
```

**2. Только семантический поиск:**
```bash
python cli.py search "ваш запрос" --top-k 5 --no-hybrid
```

**Гибридный поиск** использует:
- **Семантический поиск** - поиск по смыслу через embeddings
- **Keyword поиск (BM25)** - поиск по ключевым словам
- **Reciprocal Rank Fusion (RRF)** - комбинирование результатов обоих методов

Опции:
- `--top-k` - количество результатов (по умолчанию: 5)
- `--hybrid/--no-hybrid` - использовать гибридный поиск или только семантический (по умолчанию: `--hybrid`)
- `--semantic-weight` - вес семантического поиска в гибридном режиме (0.0-1.0, по умолчанию: 0.5)
- `--keyword-weight` - вес keyword поиска в гибридном режиме (0.0-1.0, по умолчанию: 0.5)
- `--db-path` - путь к базе данных ChromaDB
- `--ollama-url` - URL Ollama API
- `--embedding-model` - модель для embeddings

**Примеры:**
```bash
# Гибридный поиск с равными весами (по умолчанию)
python cli.py search "зачет тактика" --top-k 10

# Больше веса семантическому поиску
python cli.py search "зачет тактика" --semantic-weight 0.7 --keyword-weight 0.3

# Только семантический поиск
python cli.py search "зачет тактика" --no-hybrid
```

### Генерация поста

Генерирует пост на указанную тему, используя похожие сообщения из базы данных:

```bash
python cli.py generate "Тема поста" --query "поисковый запрос" --top-k 5
```

**Как это работает:**
1. **`topic`** (первый аргумент) - тема поста, который нужно сгенерировать
2. **`--query`** - поисковый запрос для поиска похожих сообщений в базе данных (обязательно)
3. Система находит похожие сообщения по `--query` используя семантический поиск
4. LLM генерирует пост на тему `topic`, используя найденные сообщения как контекст

**Важно:** `topic` и `--query` могут отличаться:
- `topic` - это тема, о которой вы хотите написать пост
- `--query` - это запрос для поиска релевантных сообщений в БД

**Примеры правильного использования:**

```bash
# Тема: "Зачет по тактике", ищем сообщения про "тактику" и "зачет"
python cli.py generate "Зачет по тактике" --query "зачет тактика" --top-k 10

# Тема: "Искусственный интеллект", ищем сообщения про "машинное обучение"
python cli.py generate "Искусственный интеллект" --query "машинное обучение нейросети" --top-k 5

# Тема: "Программирование", ищем сообщения про "код" и "разработку"
python cli.py generate "Программирование" --query "код разработка программирование" --top-k 8
```

**Совет:** Сначала используйте команду `search` для проверки, какие сообщения найдутся по вашему запросу:
```bash
python cli.py search "зачет тактика" --top-k 10
```

Опции:
- `--query` - поисковый запрос для нахождения похожих сообщений (обязательно)
- `--top-k` - количество похожих сообщений для контекста (по умолчанию: 5)
- `--hybrid/--no-hybrid` - использовать гибридный поиск или только семантический (по умолчанию: `--hybrid`)
- `--semantic-weight` - вес семантического поиска в гибридном режиме (0.0-1.0, по умолчанию: 0.5)
- `--keyword-weight` - вес keyword поиска в гибридном режиме (0.0-1.0, по умолчанию: 0.5)
- `--db-path` - путь к базе данных ChromaDB
- `--ollama-url` - URL Ollama API
- `--embedding-model` - модель для embeddings
- `--llm-model` - модель для генерации (по умолчанию: `devstral-2:123b-cloud`)
- `--temperature` - температура генерации 0.0-1.0 (по умолчанию: 0.7)
- `--max-tokens` - максимальное количество токенов

## Примеры

1. Индексация сообщений:
```bash
python cli.py index --data-path data/result.json
```

2. Поиск похожих сообщений:
```bash
python cli.py search "программирование" --top-k 10
```

3. Генерация поста:
```bash
# Сначала проверьте, какие сообщения найдутся:
python cli.py search "зачет тактика" --top-k 10

# Затем сгенерируйте пост:
python cli.py generate "Зачет по тактике" --query "зачет тактика" --top-k 10 --temperature 0.8
```

**Объяснение параметров:**
- `"Зачет по тактике"` - это **тема** поста (о чем писать)
- `--query "зачет тактика"` - это **поисковый запрос** для поиска похожих сообщений в БД
- `--top-k 10` - использовать 10 самых похожих сообщений как контекст

## Примечания

- Первый запуск индексации может занять время в зависимости от количества сообщений
