# Инструкция по установке модели LLM

## Рекомендуемая модель: TinyLlama

**Размер:** ~637 МБ (помещается в 1 ГБ)  
**Описание:** Компактная языковая модель, хорошо работает для RAG систем

## Установка модели

### Шаг 1: Убедитесь, что Ollama запущен

```bash
# Проверьте, что Ollama работает
curl http://localhost:11434/api/tags

# Если Ollama не запущен, запустите его:
ollama serve
```

### Шаг 2: Установите модель TinyLlama

```bash
ollama pull tinyllama
```

Это займет несколько минут в зависимости от скорости интернета.

### Шаг 3: Проверьте установку

```bash
ollama list
```

Вы должны увидеть `tinyllama` в списке установленных моделей.

### Шаг 4: Протестируйте модель

```bash
ollama run tinyllama "Привет, как дела?"
```

Если модель отвечает, значит все установлено правильно!

## Альтернативные модели (если TinyLlama не подходит)

Если нужна модель еще меньше или больше, можно использовать:

### Очень маленькие модели (< 500 МБ):
- `qwen2:0.5b` - около 300 МБ
- `phi-2` - около 1.6 ГБ (чуть больше 1 ГБ, но очень качественная)

### Компромиссные варианты:
- `gemma:2b` - около 1.4 ГБ (качественная, но больше 1 ГБ)
- `llama3.2:1b` - около 1.1 ГБ (если доступна)

## Настройка в проекте

После установки модели, убедитесь, что в `.env` файле указана правильная модель:

```env
LLM_MODEL=tinyllama
```

Или оставьте значение по умолчанию в `ollama_config.py` (уже установлено `tinyllama`).

## Проверка работы

После установки модели запустите бота:

```bash
python bot.py
```

Бот автоматически будет использовать установленную модель для генерации ответов.
